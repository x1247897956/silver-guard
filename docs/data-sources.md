# 数据来源与审核边界

本数据集是合成对话，不是原始案件记录。既有生成记录写有模型信息，但没有保存逐次生成时读取网页的日志，因此不能声称以下网页是每条旧样本生成时的直接来源。

本次审核用以下公开宣传材料核对手法分类，只保留风险信号与诱导话语，不复制受害人信息、具体作案步骤或原文案例：

- [福建省公安厅：公安部公布十大高发电信网络诈骗类型](https://gat.fujian.gov.cn/ztzl/fjjffpzxrx/zhxx/202407/t20240715_6483275.htm)：身份冒充、客服退款、虚假投资、婚恋交友等分类参考。
- [爱辉区政府：解密养老骗局，防范养老诈骗](https://www.ahq.gov.cn/jczwgk/jczwgk_qbj/jczwgk_ylfw/jczwgk_ylfw_ssqk/202603/t20260306_2738991.html)：养老投资、健康诱导与冒充亲友等分类参考。

审核由 Codex AI 助手逐案阅读完成，纠正资金请求轮次、风险标注和分类，并移除真实机构、软件与号码。没有独立人类标注员签核或双人一致性测量；结果只能用于本合成集内的实验，不代表真实人群效果。逐条审核记录与冻结哈希见数据集审计文件。
